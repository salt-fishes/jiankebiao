# 教务系统课表格式与 OCR 变体知识库

写规则包前先读。这些是从真实导出与 OCR 实战里踩出来的规律。

## 常见教务系统的导出形态

| 系统/形态 | 文本特征 | 规则包思路 |
|---|---|---|
| 正方（文本层 PDF/像素 PDF 的 OCR） | `课名★` 换行 `(1-2节)1-3周,5-15周/校区:下沙/楼号:环宇楼/场地:…/教师:张三/教学班:…/教学班组成:…/选课备注:/学分:3.5` | 键值式：keyMap 直接映射；表头锚「时间段」 |
| 强智/Web 图标行式 | `课名★` 换行 `◎ (1-2节)1-4周,6-11周` 换行 `📍 新校区 图信楼B305` 换行 `👤 张三(高等学校教师/讲师)` 换行 `(2026-2027-1)-XX12345-67` | 行前缀式 + positionalTeacher；教师括注会被解释器自动剥离 |
| 强智 PDF（像素字，位置式） | `课名(理论)` 换行 `教师【1-6,10-18周】` 换行 `N6-403` 换行 `课名(学科基础课)-理论035`（教学班说明尾随） | typeMarks 用 `(理论)` 等后缀；卡面无节次（PDF 左轴数字列回填）；教师「名+【」同行与教室首个匹配由解释器在 positionalTeacher/positionalRoom 开关下处理，包里无需写正则 |
| 截图课程卡（各课表 App） | `课名` 换行 `@校区 楼宇门牌（智慧教室）` 换行 `教师名` | 行前缀 `@`→room + positionalTeacher；多行断裂的地点会被拼进 room 值 |
| 表格 H5（每行一课的列表式） | 无网格，一行一课 | 当前解释器只支持网格/卡片，暂不支持，不要硬写包 |

## OCR 高频变体（写正则时必须兼容）

- 冒号 `:` 常被识别成全角 `：` 或中点 `·`/`・`，甚至整个读成**空格**（"教师 张三"）
  → fieldSeparators 写全 `:：·・ `（内置正方包已带空格兜底）；
- `○`（实验）被识别为 `〇`/`O`/`0` → markAliases 映射；行尾 `0` 由
  `trailingZeroFallback` 兜底（仅当去 0 后含 CJK）；
- 属性区换行会把字段切断：`校区:下\n沙` → 解释器先把块内所有行拼接再匹配，
  所以正则**不要依赖换行**；
- 图例/装饰行会以 `: 集中实践 ★: 讲课…` 的碎片形式出现，冒号开头不算特征，
  靠 `legendWords` 过滤；
- 全角/半角括号混用：课名规范化会把 `（）` 归一为 `()`，正则里写半角即可；
- **「暗色文字」判定用灰度亮度而非单通道**：正方网页的课程文字是蓝色
  （max 通道 ≈200+，看着"深"但最大通道不低），按 max 通道判定会全部漏掉；
  灰度亮度（0.299R+0.587G+0.114B）对蓝/红/绿饱和字都 ≈130 左右，稳定可用；
- 教务网页网格表的**行高不均匀**（上午/下午/晚上之间有午休、晚饭空档，
  合并单元格文字偏在单元格中下部）——不要假设节次行等距；占用识别对这类
  表格走「文字块聚类」而不是逐行带采样，规则包作者无需关心，但手动核对
  识别结果时别对行高差异感到意外。

## 周次与节次的常见写法

- 周次：`1-3周,5-15周` / `9周` / `1-16周(单)` / `1-16周(双)`；
  解释器按 `,`/`，`/`;` 分段展开，单双按 `paritySingle`/`parityDouble` 过滤奇偶；
- 节次：`(1-2节)` 是主流；也有 `第1-2节`（sectionsPattern 需改为 `第?(\d+)-(\d+)节?`）；
- 连堂课合并显示（如 6-8 节一门课）是常态，不是解析错误。

## 指纹（match.anyOf）怎么选

选「这个系统必然出现、别的系统很少出现」的子串：

- 正方：字段 key 本身就是指纹（`校区:` `教学班组成` `选课备注`）；
- 强智类：职称固定文案（`高等学校教师`）、空地点占位（`未排地点`）；
- 学期编号 `(2026-2027-1)-` 也常见但会随年份失效，**不要用它做指纹**；
- minHits=2 起步：单一词条命中太容易误配到内置包。

## 规则包调试技巧

- 应用内「我的 → 解析规则包」可查看每个包的指纹词条；
- PDF 导入会写 `ocr_debug.txt`（应用私有目录），自查列边界与块拆分问题；
- 同 id 重新导入即覆盖，改规则后直接重导；
- 截图识别路径：先确认「课表对比」功能里同一张截图的占用格识别是正确的，
  占用错了先修截图质量（完整表格、无遮挡、无深色模式反色）再谈字段。
